📚 Cara Mendapatkan API Keys (Semua Gratis!)

1. Groq (Recommended):
  • Buka: console.groq.com
  • Login dengan Google → API Keys → Create API Key
  • Gratis unlimited! Model terbaru & tercepat
2. OpenRouter (Multi-Model):
  • Buka: openrouter.ai
  • Login → Keys → Create Key
  • Akses ke GPT-4, Claude, Gemini, dll dalam 1 API!
3. HuggingFace (Open Source):
  • Buka: huggingface.co/settings/tokens
  • Create token → Role: Read
  • Gratis, banyak model open source
